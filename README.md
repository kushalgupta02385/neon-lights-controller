# neon-lights-controller
⚡ High-performance Windows desktop controller for MagicLantern Bluetooth LE addressable neon rope lights (MELK-OA10/ELK). Features a Cyberpunk React 18 Glassmorphism UI, real-time WASAPI digital audio loopback game/music sync, 213 hardware IC modes, rolling lines with black gaps, and a standalone 100% offline executable.
